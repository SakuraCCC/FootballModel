# 模型设计

Phase 4 已实现第一版可运行预测管线。所有模型只使用已标准化、可追溯的数据快照、比赛与赛果；每次执行写入模型版本、输入快照引用、输出与置信度。

- Poisson：根据近期真实进失球与联赛平均进球生成比分分布和胜平负概率。
- Dixon-Coles：在 Poisson 分布上对低比分相关性进行校正，版本 `dixon_coles_v1`。
- Elo：按时间顺序从已保存赛果更新球队强度，并输出主场调整。
- Ensemble：综合 Poisson、Dixon-Coles 与可用 Elo 调整，输出方向、进球区间、BTTS 与候选比分。
- 10,000 次确定性种子模拟从模型比分分布抽样；若比分分布过散，会降低置信度。
- 三轮复核依次记录基础进球模型、实力/状态/主客场、体能/伤停/数据质量。未保存的伤停或体能数据绝不补造，且会体现在置信度原因中。

模型缺少两队至少三场历史赛果或联赛平均进球时返回 `not_available`，并保存原因。
